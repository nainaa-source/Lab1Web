# Praktikum HTML Dasar

Proyek latihan HTML dasar untuk mata kuliah Pemrograman Web.

## Tag HTML yang Digunakan
- **Struktur**: `<!doctype>`, `<html>`, `<head>`, `<body>`
- **Teks & Judul**: `<h1>` - `<h3>`, `<p>`
- **Format Teks**: `<b>`, `<i>`, `<strong>`, `<sub>` (subscript), `<sup>` (superscript)
- **Elemen Media**: `<img>`
- **Navigasi**: `<nav>`, `<a>`
- **Daftar (List)**: `<ul>` (tidak berurutan), `<ol>` (berurutan)
- **Pemisah**: `<hr>`
